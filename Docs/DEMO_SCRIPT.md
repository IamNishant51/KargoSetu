# DEMO SCRIPT

Scenario: SAIL-style bulk cargo requirement from an overseas origin to an East Coast Indian destination.

## Minute 1
- **Problem Statement**: We begin by highlighting the reactive spot-market decision making process currently in use.
- **Action**: Enter a new procurement requirement on the dashboard for coal, overseas to Haldia.
- **Click Path**: Dashboard -> New Requirement -> Fill form (Cargo: Coal, Destination: Haldia) -> Submit.

## Minute 2
- **Action**: The system computes and displays the 90-day freight forecast (P10/P50/P90).
- **Speaking Cue**: "Here we see the predictive models for our freight rates, allowing us to choose the most cost-effective entry point. Notice the P10, P50, and P90 uncertainty bands showing the realistic variance."
- **Click Path**: Scroll to Freight Forecast Chart.

## Minute 3
- **Action**: Show entry-window recommendation and the vessel candidates.
- **Action**: Reject a vessel because its draft is incompatible with the destination port.
- **Speaking Cue**: "The platform checks real port constraints. Here, this vessel is rejected because its draft exceeds Haldia's allowable draft."
- **Click Path**: Vessel Recommendations -> Expand rejected vessel -> View constraint reason.

## Minute 4
- **Action**: Select a feasible vessel.
- **Action**: Show spot vs short-term vs medium-term contract comparison in the What-If Simulator.
- **Action**: Trigger a congestion scenario. Show the recommendation change dynamically.
- **Click Path**: Select feasible vessel -> Open What-If Simulator -> Adjust Congestion slider -> Run Simulation.

## Minute 5
- **Action**: Open the God's Eye globe.
- **Action**: Provide route, vessel, port, and risk context visually.
- **Action**: Ask the AI Copilot: "Why did the recommendation change?"
- **Action**: Show the evidence and provenance in the response.
- **Action**: Generate the final Procurement Brief.
- **Click Path**: Globe View -> Select Route -> Open AI Copilot -> Ask question -> Dashboard -> Generate Procurement Brief.
