# Maintainers

## Core Maintainers

* **KargoSetu Team** - Lead Maintainers

## Responsibilities

As a maintainer of this project, responsibilities include:

* **Merging Pull Requests**: Reviewing, approving, and merging code contributions from the community.
* **Triaging Issues**: Categorizing, tagging, and responding to bug reports and feature requests.
* **Enforcing the Code of Conduct**: Ensuring a welcoming and respectful environment for all contributors and addressing any violations.
* **Guiding Contributors**: Helping new and existing contributors navigate the codebase and contribution process.
